	Prints the contents of the current directory

	Returns user to their home directory

3-listfiles

	Returns contents of current directory in long format

	Deletes the 'betty' file from /tmp/my_first_directory

	Move back to the previous working directory

11-lists

	Lists the contents of the current directory, parent directory and boot directory, including hidden files	, in long format.
